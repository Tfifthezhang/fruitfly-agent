# Optimization Examples

[Up: Examples](../README.md)

Task packs for the normal `/optimize` workflow. They are manually authored demonstrations, not formal benchmarks or measured improvement claims.

| Pack | Scoring | Search / independent cases |
|---|---|---|
| [Python functions](python_functions/README.md) | Restricted function-call tests | 8 train, 4 selection, 6 holdout |
| [Ticket triage](ticket_triage/README.md) | Exact normalized labels | 8 train, 4 selection, 6 holdout |

Install a complete pack into a new workspace task-packs directory. `baseline.txt` is an optional reference; the active target supplies the search baseline. Read [Task packs](../../fruitfly_agent/lab/optimization/TASK_PACKS.md) before authoring your own.
