# Read a Layered Batch

[Up: Organizer](../../README.md)

The method supplies a batch directory first, then allows paged catalog, search and
original reads. `submit_organization` validates readable sections and supplied
citations, plus bounded structured findings with distinct issue IDs. Invalid final text can be repaired within the organizer invocation.
The role labels causal hypotheses separately from facts, counterevidence and
unknowns. It cannot edit candidates or certify a cause.

`defaults.yaml` owns the registered I instructions and is a frozen runtime resource.
The output contains batch, guide and source resources. Originals remain references
outside the candidate's writable allocation; binary data is available on demand.

The method adopts progressive disclosure as described in
[Anthropic's context engineering guidance](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents).
It does not implement semantic clustering, a vector database, or the learning and
update procedures of prompt optimization papers. The current shared reader still
loads selected source bytes in host memory.

Reading is bounded by the shared evidence supply and request-space checks.
Submit a compact guide using supplied citations and declare uncovered scope when
reading is exhausted. Invocation requirements are delivered directly in the role
mission. Offline Eval indexing does not invoke this model role.
