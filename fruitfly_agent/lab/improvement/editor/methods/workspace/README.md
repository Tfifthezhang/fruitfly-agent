# Edit a Granted Candidate Workspace

[Up: Editor](../../README.md)

`algorithm.py` implements the public `AgentEditor` entry exported by the editor
package. `defaults.yaml` owns its I prompts and target-directory settings.
`instructions.py` and `configuration.py` in the owner validate these values;
Catalog registers this resource through the existing Improvement surface.

The model can read directly or delegate evidence investigation through the selected
research host. It edits one detached candidate, then submits grounded reasons.
Invalid submissions retain the draft and supplied evidence for repair. The method
has no execution, publication or activation authority. Tool schemas, source grants
and validation remain Python contracts.

Customize a workspace I component through its ordinary `file` reference. Partial
configuration resolves owner defaults; frozen exports retain full effective values.
Only explicitly granted instruction fields are candidate-editable. Presentation
settings and identities are protected. Source configuration stays unchanged during
trials. Source/default changes enter frozen identity and retained-part conditions.

Offline checks: `tests.lab.test_editor_execution`, `tests.lab.test_detached_editor`,
`tests.run.test_parameter_defaults`. Fake Providers prove wiring, not proposal quality.
